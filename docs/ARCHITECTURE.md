# Architecture

## Presentation
TypeScript + React + CSS

## Application
TypeScript service/API layer

## Persistence
MySQL 8+

## Interchange
XLSX/CSV

## Documents
Object/file storage

## Security
Authentication + role-based access control

## Audit
Immutable application event records

The model is industry-neutral. Industry-specific workflows should be implemented through configuration, templates, job types, asset categories, checklists, and custom fields.
