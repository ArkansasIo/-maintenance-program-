# Canada Workplace Maintenance — Universal Edition

Universal workplace maintenance management system foundation.

## Modules
- Dashboard
- Work Orders
- Preventive Maintenance
- Inspections
- Assets
- Inventory / Parts
- Vendors
- Employees / Teams
- Locations
- Documents
- Reports
- Administration / RBAC
- Audit history
- Excel import/export

## Suggested stack
- TypeScript
- React + Vite
- Node.js API
- MySQL 8+
- CSS
- Excel XLSX import/export
- Mermaid UML

The model is intentionally industry-neutral: workflows are configured through job types, asset categories, checklists, templates, and custom fields.
